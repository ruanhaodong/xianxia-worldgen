# 仙侠世界地图生成器（Xianxia Worldgen）

引擎无关的程序化世界数据生成系统原型：在服务器或本地生成**地球尺度**（半径 ≈ 6371 km）的仙侠星球数据；Unity / UE / Three.js 等渲染器只负责读取与展示。本仓库同时提供：

- **Node CLI（无头）**：独立于渲染生成骨架与摘要数据
- **浏览器查看器**：2D 等矩形全球概览 + 3D 立方体球 LOD 星球，支持从太空无缝缩放到地面；地面层有树林/草地/房屋/城镇/道路/宗门建筑；NPC 行人；可「成为角色」第三人称行走（含手机摇杆）

在线预览：<https://ruanhaodong.github.io/xianxia-worldgen/>

## 架构概览

```
生成管线（确定性，禁止 Math.random）
  种子 seed ──► 大陆/海洋 ──► 山脉高程（类板块脊线 + 仙侠险峰/深谷）
            ──► 河流湖泊（高程场上的汇流累积，非随机摆放）
            ──► 气候生态（纬度 + 海拔 → 温度；噪声 → 湿度 → 生物群系）
            ──► 局部地貌 / 洞府位点（洞穴为局部 3D 占位 stub）
            ──► 宜居度 → 聚落峰值落点 → 地形最小代价道路
            ──► 依山与灵气资源落宗门
            ──► 人工覆盖层 JSON（可选，叠在程序化结果之上）

空间结构
  立方体球 6 面 + 每面四叉树 LOD
  全球低精度骨架（等矩形）预生成
  局部 chunk 按需生成 + LRU 缓存淘汰
  相邻块无缝采样；裙边（skirt）缓解 LOD 裂缝
  近地（约 < 2.5 km）确定性流式地面细节（InstancedMesh）+ NPC
```

| 目录 | 说明 |
|------|------|
| `src/core/` | 哈希噪声、立方体球、四叉树、世界会话 |
| `src/geo/` | 地形、气候、河流、洞府、覆盖层 |
| `src/settlement/` | 宜居度、聚落、道路、宗门 |
| `src/cli/` | 无头生成与确定性测试 |
| `public/` | 静态 Web 查看器（含地面细节 / 角色控制） |
| `public/js/viewer/` | Three.js 查看器：main / groundDetail / npcs / player / geometries |
| `data/` | CLI 输出与示例覆盖层 |

**同一坐标 + 同一种子 ⇒ 同一山河道路与地面细节**（基于哈希的连续噪声，无 `Math.random`）。

## 快速开始

```bash
cd xianxia-worldgen
npm install
node scripts/build-viewer.mjs   # 将生成模块与 three 拷入 public/js

# 无头生成
npm run cli -- --seed "九州·42" --out data/world

# 确定性自检（同种子两次摘要必须相等）
npm run test:determinism

# 静态服务器
npx --yes serve public -l 4173
# 浏览器打开 http://localhost:4173

# 无头截图（含地面与角色行走）
npm run screenshot
```

### CLI 参数

```
node src/cli/generate.mjs --seed <种子> --out <目录> [--width 256] [--height 128] [--overrides data/overrides.example.json]
```

输出包括：`meta.json`、`summary.json`、`elevation.f32`、`biome.u8`、`digest.txt`、`preview.ppm`，并同步到 `public/data/` 供查看器使用。

## 查看器操作

### 轨道模式（默认）

- **种子输入** → 点「生成世界」
- **图层开关**：高程 / 生态 / 河流 / 聚落 / 道路 / 宗门
- **3D**：拖拽旋转、滚轮 / 捏合缩放（太空 → 地面）
- 缩放到约 **2.5 km** 高度以下时，自动流式生成地面细节：
  - 按生物群系变化的树木（针叶 / 阔叶 / 竹林·云雾林）
  - 草地、岩石
  - 聚落房屋与城镇布局、山间宗门宝塔
  - 贴地道路折线
  - 城镇 / 道路上的 NPC 行人（程序化骨骼摆动行走）

### 飞行模式

按钮「切换飞行模式」：

- WASD 移动，Shift 加速（封顶 **1000 m/s**）
- 空格上升，Ctrl 下降
- Q / E 调节基础速度

### 地面角色模式

按钮「**进入地面 / 成为角色**」：在当前视角落点（优先附近聚落）生成可操作角色。

| 操作 | 桌面 | 手机 |
|------|------|------|
| 移动 | WASD / 方向键 | 左下虚拟摇杆 |
| 视角 | 在画面右侧拖拽 | 右侧拖拽 |
| 奔跑 | Shift | — |
| 跳跃 | 空格 | — |
| 退出 | 再点「退出地面 / 返回轨道」 | 同左 |

第三人称相机跟随角色，并贴合地表高程。手机浏览器会降低像素比、实例数量与视距以保证流畅。

## 人工覆盖层

见 `data/overrides.example.json`。可在程序化结果上叠海拔补丁或强制陆地，作为独立数据层保存，便于策划手工微调。

## 设计对应关系（需求对照）

1. **引擎无关数据层** + 地球半径 + 太空到地面缩放 + 御剑飞行 ≤ 1000 m/s → 已实现
2. **立方体球 + 四叉树 LOD**、骨架预生成、按需缓存 LRU、确定性、裙边缝合 → 已实现
3. **自然地理生成顺序**、汇流河流、仙侠险峰/深谷/岩层/云雾林/洞府标记、高度场 + 洞穴 stub、覆盖层 → 已实现（洞穴仅为局部 3D stub）
4. **聚落/道路由宜居度与最小代价生长、宗门依山依资源** → 已实现（骨架分辨率下的近似）
5. **地面详实内容（林/草/屋/城/路）+ NPC + 可进入行走** → 已实现（浏览器原型，程序化低模 + InstancedMesh 流式加载）

## 已知限制

- 地面细节为示意级低模，非影视级植被；实例数量在手机上有上限
- 高度夸张随相机高度变化，重建 LOD 时可能有短暂闪烁
- NPC 沿道路为骨架折线插值，不会做复杂避障
- 洞穴仅为数据层 stub，尚未体素化可进入地下
