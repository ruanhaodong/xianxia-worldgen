# 仙侠世界地图生成器（Xianxia Worldgen）

引擎无关的程序化世界数据生成系统原型：在服务器或本地生成**地球尺度**（半径 ≈ 6371 km）的仙侠星球数据；Unity / UE / Three.js 等渲染器只负责读取与展示。本仓库同时提供：

- **Node CLI（无头）**：独立于渲染生成骨架与摘要数据
- **浏览器查看器**：2D 等矩形全球概览 + 3D 立方体球 LOD 星球，支持从太空缩放到近地，以及最高 **1000 m/s** 的飞行模式

## 架构概览

```
生成管线（确定性，禁止 Math.random）
  种子 seed ──► 大陆/海洋 ──► 山脉高程（类板块脊线 + 仙侠险峰/深谷）
            ──► 河流湖泊（高程场上的汇流累积，非随机摆放）
            ──► 气候生态（纬度 + 海拔 → 温度；噪声 → 湿度 → 生物群系）
            ──► 局部地貌 / 洞府位点（洞穴为局部 3D 占位 stub）
            ──► 宜居度 → 聚落峰值落点 → 地形最小代价道路
            ──► 依山与灵气资源落宗门
            ──► 人工覆盖层 JSON（可选，叠在程序化结果之上）

空间结构
  立方体球 6 面 + 每面四叉树 LOD
  全球低精度骨架（等矩形）预生成
  局部 chunk 按需生成 + LRU 缓存淘汰
  相邻块无缝采样；裙边（skirt）缓解 LOD 裂缝
```

| 目录 | 说明 |
|------|------|
| `src/core/` | 哈希噪声、立方体球、四叉树、世界会话 |
| `src/geo/` | 地形、气候、河流、洞府、覆盖层 |
| `src/settlement/` | 宜居度、聚落、道路、宗门 |
| `src/cli/` | 无头生成与确定性测试 |
| `public/` | 静态 Web 查看器 |
| `data/` | CLI 输出与示例覆盖层 |

**同一坐标 + 同一种子 ⇒ 同一山河道路**（基于哈希的连续噪声，无 `Math.random`）。

## 快速开始

```bash
cd xianxia-worldgen
npm install
node scripts/build-viewer.mjs   # 将生成模块与 three 拷入 public/js

# 无头生成
npm run cli -- --seed "九州·42" --out data/world

# 确定性自检（同种子两次摘要必须相等）
npm run test:determinism

# 静态服务器
npx --yes serve public -l 4173
# 浏览器打开 http://localhost:4173
```

### CLI 参数

```
node src/cli/generate.mjs --seed <种子> --out <目录> [--width 256] [--height 128] [--overrides data/overrides.example.json]
```

输出包括：`meta.json`、`summary.json`、`elevation.f32`、`biome.u8`、`digest.txt`、`preview.ppm`，并同步到 `public/data/` 供查看器使用。

### 查看器操作

- **种子输入** → 点「生成世界」
- **图层开关**：高程 / 生态 / 河流 / 聚落 / 道路 / 宗门
- **3D**：拖拽旋转、滚轮缩放（太空→地面）
- **飞行模式**：WASD 移动，Shift 加速（封顶 1000 m/s），空格上升，Ctrl 下降，Q/E 调节基础速度

## 人工覆盖层

见 `data/overrides.example.json`。可在程序化结果上叠海拔补丁或强制陆地，作为独立数据层保存，便于策划手工微调。

## 设计对应关系（需求对照）

1. **引擎无关数据层** + 地球半径 + 太空到地面缩放 + 御剑飞行 ≤ 1000 m/s → 已实现（查看器原型）
2. **立方体球 + 四叉树 LOD**、骨架预生成、按需缓存 LRU、确定性、裙边缝合 → 已实现
3. **自然地理生成顺序**、汇流河流、仙侠险峰/深谷/岩层/云雾林/洞府标记、高度场 + 洞穴 stub、覆盖层 → 已实现（洞穴仅为局部 3D stub）
4. **聚落/道路由宜居度与最小代价生长、宗门依山依资源** → 已实现（骨架分辨率下的近似）

## 已知简化 / 占位

- 骨架分辨率默认 256×128，非实时行星流式分页服务
- 洞穴为入口位点 + `local3d` stub，未展开完整体素洞府
- LOD 形态过渡以裙边与连续采样为主，未做几何 morph 目标融合
- 道路为网格最小代价路径，未做等级路网与桥梁细节
- 三渲二夸张系数便于从太空辨认地貌，真实游戏中应按引擎比例尺调整
